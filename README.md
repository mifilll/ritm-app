# Ритм — личная система привычек

Мобильное веб-приложение для распорядка дня, питания и здоровья. Интерфейс адаптирован для iPhone: тёмная тема, стеклянные элементы и нижняя навигация.

## Запуск

Откройте `index.html` в браузере или опубликуйте содержимое репозитория через GitHub Pages. Никакой сборки и установки зависимостей не требуется.

## Публикация на GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. Через некоторое время сайт будет доступен по адресу `https://mifilll.github.io/ritm-app/`.

## Данные

Записи хранятся локально в браузере устройства. Для переноса используйте экспорт резервной копии в настройках. Данные пока не синхронизируются автоматически между устройствами.

## Технологии

- HTML, CSS и vanilla JavaScript
- Локальное хранилище браузера
- Адаптивный интерфейс и CSS-эффекты Liquid Glass
